# BuildMate MVP Requirements

## Roles
Customer, contractor/company member, supplier staff, driver/transporter, professional, administrator and super administrator.

## MVP modules
Authentication; role onboarding; supplier verification; master catalogue; supplier listings; location-based search; quotation requests; supplier quotations; cart and orders; payments; delivery assignment; proof of delivery; invoices; reviews; disputes; notifications; reports; audit logs.

## Non-functional requirements
Mobile-first responsive design; WCAG-minded accessibility; role and organisation isolation; secure webhook handling; idempotent financial operations; encrypted transport; backup and restore procedures; activity auditing; acceptable page performance on mobile data; graceful error states.

## Acceptance baseline
A verified customer can request or select materials, receive/accept a supplier offer, pay, see the order move through fulfilment and confirm a documented delivery. Administrators can review every critical state change and financial reference.
